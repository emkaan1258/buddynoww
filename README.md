# Buddynoww replica (React + Vite + Tailwind)

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # production build in dist/

Images load from https://buddynoww.com/images/*. To self-host, download them into `public/images/`
and set `BASE = '/images'` in `src/data/site.js`.

See the "What needs verifying" notes in the chat reply / `src/data/site.js` comments.
